# 🚀 Clone Spotify

Progetto frontend sviluppato in team con l’obiettivo di ricreare fedelmente l’interfaccia desktop di Spotify, replicando layout, navigazione e principali funzionalità di consultazione e ricerca di brani, album e artisti, senza implementazione della parte backend di streaming reale.

---

## 🧠 Overview

- Clone frontend dell’interfaccia desktop di Spotify
- Riproduzione fedele di layout, sidebar e player UI
- Sistema di navigazione tra home, ricerca e libreria
- Visualizzazione di album, artisti e playlist
- Focus sull’esperienza utente e sulla UI/UX
- Nessuna integrazione backend per lo streaming reale

## ⚙️ Tech Stack

### 🌐 Frontend
- HTML
- JavaScript
- Sass / CSS
- Bootstrap

### 🧪 Tools
- Node.js
- Git

## 🔐 Features

- Home page con layout simile a Spotify desktop
- Sidebar di navigazione (Home, Search, Library)
- Pagina ricerca con risultati artisti/album
- Visualizzazione dettagli album e artisti
- UI player musicale statico (non funzionale allo streaming reale)
- Interfaccia fedele al design originale
- Gestione dati tramite API o mock data

## ⚙️ Setup

### 📦 1. Clona il progetto
```bash
git clone https://github.com/luke-wb/BuildWeek2-Spotify.git
```

### 🚀 2. Avvia il progetto
```bash 
Apri il progetto con Visual Studio Code e avvia il file homepage.html direttamente nel browser (oppure usa l’estensione Live Server per Visual Studio Code).
```
